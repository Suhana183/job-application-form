# 💼 Job Application Form

A simple, clean, and responsive **Job Application Form** built using **HTML, CSS, and JavaScript**.

## 📌 Features

* 🧑 Applicant Name field
* 📧 Email field
* 📱 Phone Number field
* 💬 Message field
* ⚠️ Form validation and error messages
* ✅ Application submission button
* 📱 Responsive user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Job-Application-Form/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
